# AGENTS.md

This file provides guidance to Codex (Codex.ai/code) when working with code in this repository.

## Project overview

This is a [Quarto](https://quarto.org) website (`project: type: website`) containing lecture materials in Indonesian for a university course taught by Rizqy Amelia Zein (Departemen Psikologi, Universitas Airlangga). Per `_quarto.yml`/`index.qmd`/`README.md`, the site topic is **"Peran Akal Imitasi dalam Proses Pembelajaran dan Penelitian"** (the role of AI/"imitated intellect" in learning and research). The site is a work in progress — most content has not been written yet.

## Commands

Quarto CLI commands (run from the repo root):

```bash
quarto preview
```
Live-reloading local preview of the whole site.

```bash
quarto render
```
Renders the full site to `docs/` (the configured `output-dir`), per `render:` in `_quarto.yml`.

```bash
quarto render slides/bagian-1.qmd
```
Renders a single file (swap the path for any qmd).

There is no separate lint/test tooling in this repo — validity is checked by whether `quarto render` completes without errors.

## Folder structure (tentative)

```
akal-imitasi/
├── _quarto.yml       # site config — navbar, render list, theme
├── index.qmd         # homepage
├── slides/           # reveal.js slide decks, one per bagian
├── materials/        # (planned) readings, worksheets, handouts
├── articles/         # (planned) standalone written pages
├── img/              # (planned) images used across slides/pages
├── libs/             # (planned) shared JS/CSS assets
├── references/       # source PDFs/reading material (gitignored, local only)
├── _extensions/      # vendored Quarto extensions (UNAIR theme, icons)
└── docs/             # rendered site output (committed, served by GitHub Pages)
```

`materials/`, `articles/`, `img/`, and `libs/` are already declared under `resources:` in `_quarto.yml` but don't exist on disk yet — they're the planned home for content that hasn't been added. Create them as needed rather than inventing other top-level locations.

## Architecture

- **`_quarto.yml`** is the single source of truth for site structure and must be kept in sync with content:
  - `render:` explicitly lists which `.qmd` files are built into the site. **Adding a new page or slide deck requires adding its path to this list**, or it will not be rendered/linked even if the file exists on disk.
  - `website.navbar` / `website.page-footer` define the navbar links (including the "Materi" menu) and footer — update here when adding new pages, not per-file.
  - `format.html` sets site-wide HTML defaults (theme, TOC, highlight style, the Font Awesome CDN include).
- **`docs/`** is the rendered output directory and is committed to the repo (not gitignored) — this is what GitHub Pages serves. It's regenerated by `quarto render`, don't hand-edit it.
- **`slides/`** holds reveal.js slide decks (e.g. `slides/bagian-1.qmd`). New decks should follow `bagian-1.qmd`'s pattern:
  - `format: unair-revealjs` (see below) with `slide-number`, `progress`, `transition: slide`, `center: false`.
  - `execute: {eval: false, echo: true}` since slides show code without running it.
  - A closing slide crediting the R/Quarto/UNAIR-theme tooling and contact info.
- **`_extensions/`** vendors three Quarto extensions used by the slides:
  - `rameliaz/unair` — the custom `unair-revealjs` format (theme `airlangga.scss` + `theme.html` include-after-body), from [quarto-unair-theme](https://github.com/rameliaz/quarto-unair-theme). This is the house style for all slide decks in this repo.
  - `mcanouil/iconify` and `quarto-ext/fontawesome` — icon shortcodes used in slide/page content.
- **`references/`** holds source PDFs and reading material used to write the course content. It's gitignored (`/references` in `.gitignore`) — it's a local working library, not part of the published site.
- **`site_libs/`** contains Quarto's generated JS/CSS dependencies for the root-level pages; it's regenerated by rendering and shouldn't be edited by hand.
- **`.quartoignore`** excludes R/RMarkdown artifacts (`*.R`, `*.Rmd`, `*.Rproj`, `rmarkdown/`, `*.pptx`) from Quarto's project handling — this repo has moved from an older R Markdown-based workflow to Quarto.
